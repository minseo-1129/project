## Problem <!-- case.section.problem -->

사용자와 쇼핑몰 각 이해관계자가 경험하는 문제

- **보유한 옷을 편리하게 정리할 수 있는 모바일 옷장 서비스 부재** · User pain point — **82%** // “옷 구매 시, 가지고 있는 옷에 어울리는 제품을 고르는 것이 어렵고, 그것을 실제로 판매하는 매장을 찾아 구매하는 과정이 불편함” // Survey · 10–30대 127명
- **사용자 옷장을 기반으로 쇼핑몰이 제품을 추천·코디하는 모바일 플랫폼 부재** · Online shop pain point — **85%** // “온라인 패션 플랫폼 수수료에 부담을 느끼며, 고객이 실제 보유한 옷을 알 수 없어 제품 추천에 한계가 있다.” // Survey · 온라인 쇼핑몰 37곳

## Journey <!-- case.section.journey -->

예비 사용자의 여정 지도

※ 말풍선 = 생각 & 감정 · → = 도출한 기능

@lanes

- **Motivation** — “다음주면 소개팅이다! 그런데 뭘 입어야 하지? 옷장 상태가 말이 아니네. :(”
- **Launch** — “클릭 몇 번으로 옷을 등록하는 기능이 정말 편리해 :)” // → 옷장 등록 과정이 간단해야 한다.
- **Engage** — “코디가 되면 알림이 오는구나? 매번 확인할 필요가 없겠어.” // “리뷰를 공개해주니 쇼핑몰 선택에 도움이 돼.” // “내 옷을 하나하나 살펴봤구나. 마음에 드니까 추천된 옷을 사야지.” // → 쇼핑몰에 대한 사용자 리뷰를 남길 수 있도록 하여, 사용자의 선택에 도움이 되도록 구성한다. // → 코디가 완료되는 경우 알림을 제공한다.
- **After use** — “쇼핑몰 가입이 귀찮았는데, 앞으로는 가입할 필요 없이 PICO에서 바로 구매해야지!” // → 구매 과정이 쇼핑몰 페이지로 넘어가거나 독자적으로 이루어지지 않아야 한다. // → PICO 계정 하나로 쇼핑몰에 접근할 수 있어야 한다.

## Business model <!-- case.section.business-model -->

사용자는 무료로, 쇼핑몰은 거래액의 3%로 — 양면 플랫폼의 비즈니스 모델 캔버스

@canvas

- **Key partners** — Naver CLOVA AI // AWS // 대학 패션학과 // 투자자
- **Key activities** — 앱 구축 // 사용자·쇼핑몰 확보 // 서비스 품질 개선
- **Key resources** — 지적 자산 — 논문, AI 기술 // 인적 자원 — 팀원 역량
- **Value propositions** — 편리성 // 만족도 // 매출 증대 // 시간 절약 // 재미·흥미 // 휴대성
- **Customer relationships** — 맞춤 추천 서비스 // 맞춤 코디 서비스
- **Channels** — 직접 채널 // 앱 플랫폼
- **Customer segments** — 패션에 관심이 적고 코디에 어려움을 겪는 20–30대 남성 // 고객 인사이트가 필요하고 고객과 소통하고 싶은 남성 쇼핑몰
- **Cost structure** — 인건비 · 앱 유지보수·제작비 · 홍보비 · 운영비 · 기술 투자비
- **Revenue streams** — 중개 수수료 3% · 데이터 보고서 구독 · 프리미엄 코디 구독

※ 출처 · pico 사업계획서 (창업 경진대회 발표 자료)

## Market <!-- case.section.market -->

43조 패션 시장 안에서, 모바일 옷장 기반 코디는 비어 있는 자리였다.

@boxed

- 43조 — 전체 시장 · 국내 패션 시장 — 통계청
- 10조 — 유효 시장 · 온라인 패션 시장 — 통계청
- 6조 — 코어 시장 · 모바일 패션 시장 — 크로키닷컴(지그재그)

### 수요 검증

@boxed

- 88% — 사용자 사용 의향 · 10–30대 127명 설문
- 78% — 쇼핑몰 사용 의향 · 온라인 쇼핑몰 37곳 설문

온라인 쇼핑몰 35곳을 포함한 협업 기관 50곳과 MOU를 맺었고, YouTube 구독자 93만 · Instagram 팔로워 30만 규모의 홍보 채널을 확보했다.

## Revenue model <!-- case.section.revenue -->

타 온라인 의류 플랫폼(5–13%)보다 낮은 3% 수수료로 쇼핑몰 유치

@meter

- 중개 수수료: 9,600만 원 — 월 매출 800만 원 쇼핑몰 × pico 경유 20% × 수수료 3% × 2,000곳
- 데이터 구독: 5,000만 원 — 옷장 데이터 리포트 월 10만 원 × 500곳
- 프리미엄 코디: 1,190만 원 — SNS 셀럽 코디 월 11,900원 × 1,000명

@boxed

- 월 1억 5천만 원+ — 예상 월 매출 (세 수익원 합계, 사업계획서 추정치)
